Quiénes Somos

Este laboratorio nace con el objetivo de democratizar el acceso a los datos demográficos de México. Procesamos bases de datos complejas para ofrecer herramientas visuales, rápidas y accesibles.

Nuestro enfoque está en transformar datos crudos en información valiosa para investigadores, estudiantes, periodistas y tomadores de decisiones.

Documentación del Sistema

Guía rápida para interpretar los indicadores y aprovechar al máximo los dashboards.

🗄️ Fuentes de Datos

  • INEGI (Datos Crudos): Conteos y censos históricos de población. Representan la "foto" real del país en años específicos.
  • CONAPO (Estimaciones y Proyecciones): Modelos matemáticos que estiman la población año con año (desde 1990 hasta 2040), basándose en tasas de natalidad, mortalidad y migración.

📊 Glosario de Indicadores

  • Razón por Sexo: Indica cuántos hombres hay por cada 100 mujeres en un año o grupo de edad. Si el valor es menor a 100, significa que hay más mujeres que hombres.
  • Pirámide Poblacional: Gráfico que muestra la distribución por edades y sexo. Hombres a la izquierda (barras negativas), Mujeres a la derecha.
  • Límites (LI y LS) y CV: Son el Límite Inferior, Límite Superior y Coeficiente de Variación. Se muestran en años censales específicos para denotar la precisión estadística.

🖥️ ¿Cómo leer los Dashboards?

1. Dashboard Normal

Ideal para explorar una sola fuente de datos. Permite ver la evolución histórica y futura de la población, la razón por sexo y cómo se transforma la pirámide de edad entre distintos años (ej. 1990 vs 2040).

2. Dashboard Comparativo

Diseñado para contrastar dos fuentes (ej. CONAPO vs INEGI). Permite ver si las proyecciones subestimaron o sobreestimaron la población real. En la pirámide, las barras transparentes con borde te permiten ver cómo se superponen las estructuras de edad de ambas fuentes.

Instrucciones de uso tras la descarga

🪟 Pasos para Windows

  1. Descomprime el archivo .zip que descargaste en cualquier carpeta de tu computadora.
  2. Haz doble clic en el archivo ConapoDashboard_v1.0.0.exe.
  3. Si aparece una pantalla azul de "Windows protegió su PC", haz clic en "Más información" y luego en "Ejecutar de todas formas".
  4. Se abrirá una ventana negra (consola) y, automáticamente, tu navegador web mostrará la aplicación.
  5. Importante: Mantén la ventana negra abierta mientras uses el dashboard. Para cerrar la aplicación, simplemente cierra esa ventana negra.

🐧 Pasos para Linux

  1. Descomprime el archivo .zip en tu carpeta de preferencia.
  2. Abre una terminal en esa carpeta y dale permisos de ejecución al archivo con el comando:
    chmod +x ConapoDashboard
  3. Ejecuta la aplicación con el comando:
    ./ConapoDashboard_v1.0.0
  4. El navegador web se abrirá automáticamente con la aplicación en funcionamiento.
  5. Importante: No cierres la terminal mientras uses el dashboard. Para cerrarlo, presiona Ctrl + C en la terminal o simplemente cierra la ventana.
Nota de seguridad: La aplicación es completamente segura, es de código abierto y no requiere instalación ni conexión a internet para funcionar. Todos los datos demográficos están empaquetados dentro del ejecutable.
